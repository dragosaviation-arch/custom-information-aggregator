# CIA v1.0.0 — Initial Public Release

**Status: Release candidate accepted — public release pending.** The v1.0.0 installer described here has passed the reported physical acceptance and packaging checks. No GitHub release, downloadable public installer asset or `v1.0.0` tag has been published yet.

## What is CIA?

**Custom Information Aggregator (CIA)** is a Windows desktop application for exploring structured **XML** document collections, choosing the information that matters, reviewing the results and exporting them to Excel workbooks.

It grew out of a practical maintenance-document workflow, but the current application is designed as a general-purpose XML information-extraction tool.

## What's included in v1

- **Load:** Add XML files, folders and supported archives; inspect included/ready source files and organize source Sets.
- **Discovery:** Inspect XML tags and structural contexts, select values and preview the selected input.
- **Output preparation:** Review proposed OutputSets and their previews; preserve structural relationships by default or opt into **One row per source file**.
- **Database and review:** Build the selected information into a reviewable Database with configurable inclusion and column presentation.
- **Excel export:** Configure workbook/worksheet destinations and export included results to native `.xlsx` files without requiring Excel to be installed.
- **Workflow assistance:** Selection and blacklist profiles, progress/status information and **Settings → Log & Diagnostics** for investigating operations.
- **Documentation:** A step-by-step [User Manual](../user-manual/README.md), [Installation Guide](../installation/README.md) and [Support](../../SUPPORT.md).

The practical workflow is **Load → Discover → Select → Build Database → Review → Export to Excel**.

## Windows distribution

The accepted candidate is a **self-contained Windows x64 desktop application** packaged in a graphical, per-user installer. The product owner reports successful physical testing on both **Windows 11 x64** and **Windows 10 x64**. Installation does not require administrator elevation or a separately installed .NET runtime.

CIA v1 is intentionally **not Windows code-signed**; Microsoft Defender SmartScreen may show an unknown-publisher warning. A **GPG-signed AAL license** provides verification of the author attribution document; it is **not** an executable signature.

Once the release is published, download the installer only from the [official CIA Releases page](https://github.com/dragosaviation-arch/custom-information-aggregator/releases). Compare its SHA-256 hash against the value below before running it. The currently accepted installer is still a **local artifact**, not a GitHub release asset.

## Known limitations

- v1 is focused on **XML**. Planned JSON, CSV and HTML input capabilities are not shipped in this release.
- The optional **One row per source file** output mode can yield wide, sparse repeated-field columns and identifiable rows with no selected values. Use the default relationship-preserving mode when a compact, family-oriented result is preferable. Further investigation is scheduled after release; no data-shaping correction is claimed here.
- Output Preview is bounded and is **not** a complete view of the published Database.
- **Working State / Recovery** and **Decomposer** are not available in the accepted v1 interface.
- Independently derived OutputSets are not automatically joined solely on matching field names.

See the complete [Known Limitations chapter](../user-manual/known-limitations.md) for context.
