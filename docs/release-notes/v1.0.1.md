## Release classification

CIA v1.0.1 is a post-release maintenance and bug-fix update to v1.0.0. It contains no new input format, workflow or user-facing feature.

## Corrected structural association

A confirmed defect could separate structurally related XML values into different records during Row Family classification and Database projection. Two generic causes were corrected:

- selector-qualified structural slots under a repeated record could be classified and flattened as separate repeated records instead of fields belonging to their proven parent record;
- Database projection initially read only selected candidates, so an unselected structural marker needed to associate selected values could be discarded before flattening.

Row Family classification and flattening now retain proven structural slots within their repeated parent record. Database projection preserves relevant unselected structural markers only as internal association context, then removes that context before publication. Consequently, selected values sharing a proven source record remain associated in the Database and flow through Extraction into the same Excel record. Unselected values and internal structural markers do not become output columns or values.

Structurally independent branches and separately repeated families remain separate by design. CIA does not invent relationships or join values solely because they occur in the same file.
