# Walkthrough — workspaces and actions

The four top-level workspaces visible in the accepted screenshots are **Load**, **Discovery**, **Database**, and **Settings**. Discovery has **Input** and **Output** modes. The Database workspace also contains the Excel preparation/export controls.

Read in sequence:

1. [Load — manage sources](load.md)
2. [Discovery Input — choose information](discovery-input.md)
3. [Discovery Output — approve the output plan](discovery-output.md)
4. [Database — review the results](database.md)
5. [Excel Export — save workbook(s)](excel-export.md)
