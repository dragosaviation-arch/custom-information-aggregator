# Manual sample data — 30 Goodbooks XML files

This directory holds the **exact 30 XML files used for the CIA User Manual's annotated screenshots and Quick Start**.

**[Download the 30-file sample ZIP](sample_files.zip)**

1. Download `sample_files.zip` from this GitHub directory.
2. Extract it to any local folder.
3. In CIA, use **Load → Add Folder** (or **Add Files**) and select the extracted XML files.
4. Follow the [Quick Start](../quick-start.md) and [Walkthrough](../walkthrough.md).

The archive contains **30 XML files**; the original filenames and contents were retained unchanged from the product owner's manual sample set. The ZIP is documentation/sample data only; it is **not bundled with the CIA application installer**.
