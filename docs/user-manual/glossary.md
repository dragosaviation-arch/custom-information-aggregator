# Glossary

| Term | Meaning in CIA |
|---|---|
| **Source** | An individual input file or supported file within a package/archive. |
| **Included source** | A loaded source enabled to participate in processing. |
| **Source Set / parent Set** | A user-managed group of input sources. |
| **Discovery** | Inspection of available input structures and selection of useful information. |
| **Input mode** | The Discovery view for source fields, contexts and source-value preview. |
| **Output mode** | The Discovery view for projected rows, output interpretation and proposed OutputSets. |
| **Logical tag** | A displayed discovered tag name before considering all distinct contexts. |
| **Detailed field / structural context** | A field distinguished by its actual source structure/path. |
| **Occurrence** | One encountered instance of a field in the source material. |
| **OutputSet / derived Set** | A proposed or materialized result table formed from selected input structures. |
| **Output Plan** | The pre-Database representation of proposed output grouping. |
| **Preserve relationships** | Default mode for relationship-preserving output tables. |
| **One row per source file** | Optional mode for a single row per included successfully interpreted XML source, with repeated values potentially spreading across numbered columns. |
| **Database** | The materialized review surface that controls included rows and columns for downstream export. |
| **SourceId** | A companion source identity that helps trace results to their source. |
| **Workbook** | An `.xlsx` file that can contain one or more worksheets. |
| **Worksheet** | One sheet; CIA uses one worksheet per enabled derived OutputSet. |
| **Blacklist** | A controlled exclusion state used in Discovery. |
| **Selection profile** | Saved configuration for information-selection choices. |
| **Current / out of date** | Status indicating whether a published processing result aligns with the active configuration. |
